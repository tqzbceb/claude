dcwatch 浏览器扩展 · 装法
==============================

Chrome / Edge（Brave 等同内核浏览器也行）
  1. 先让 dcwatch 跑起来（双击 启动.bat 或 dcwatch.exe）
  2. 地址栏输入 chrome://extensions 回车（Edge 是 edge://extensions）
  3. 右上角打开「开发者模式」
  4. 点「加载已解压的扩展程序」，选中 dcwatch-extension 文件夹
     （要选到里面有 manifest.json 的那一层）
  5. 打开 https://discord.com/channels/... 登录，切到要盯的频道
  6. ★ 在这个 Discord 页面按 F5 刷新一次 ★
     内容脚本只在页面加载时注入，装扩展之前就开着的标签页是没有它的。
     这是「什么都没发生」最常见的原因。

装好了会看到什么
  Discord 页面右下角出现一个小药丸：  ● dcwatch 正在旁听
    绿点 = 通了
    橙点 = 能连上但有事要做（比如旁听开关被关了）
    红点 = 连不上 dcwatch（没启动 / 端口不对 / 扩展要刷新）
  点药丸展开面板：本机程序在不在、这一页在盯哪个频道、已上报几条、
  服务端累计几条，还有一句「该怎么修」。面板里能发一条测试消息，
  也能直接打开 dcwatch 界面。
  不想看它 -> 点「不再显示」；想找回来 -> 页面按 F12，控制台执行 __dcwatch.show()

第二个入口：浏览器工具栏上的 dcwatch 图标
  图标角标：ON 绿 = 正常，? 橙 = 没有标签页在旁听，! 红 = 连不上
  点开有四项自检，还能改端口（不用改代码了）
  工具栏上看不到图标：点那个拼图图标，把 dcwatch 固定出来

更新扩展（我改了代码之后）★ 两步，少一步等于完全没改 ★
  把新的文件覆盖到同一个文件夹，然后：
  1. 去 chrome://extensions，点这个扩展卡片上的「刷新」小圆箭头 ⟳
  2. 回 Discord 页面按 F5
  卡片上的版本号是你唯一的自查凭据 —— 现在应该是 1.7.0。
  版本对不上时，扩展弹窗顶部和 dcwatch 界面顶部都会直接提示你去刷新。

多个 Discord 账号一起盯
  用两个浏览器（或 Chrome 里的两个用户配置），各登一个号，各装一次扩展。
  dcwatch 界面左下角会把它们分别列出来：哪个号、哪个浏览器、在盯哪个频道、
  多久前有心跳、扩展版本。消息合到同一个收信箱，每条记着是哪个号收到的。
  规则里可以只盯某个号（规则编辑器「听哪里」→「只听这些账号」）。
  两个浏览器同时开着同一个频道也不会重复：按消息 ID 去重，
  只入库一条、规则只跑一次、AI 只调一次。

注意
  - Discord 标签页要留着，网页版只渲染你当前打开的那个频道
  - 想同时盯多个频道就开多个标签页，各停在一个频道
  - 只报你挂上之后的新消息，历史消息不会上报
  - 只读不发：不碰你的 token，也不向 Discord 发任何请求
