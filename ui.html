代理只用于访问模型 API 和 Discord，不影响本机界面。 填了还是不行就把地址里的端口跟你的代理软件核对一遍。
通知、提示音、转发都在「通知与转发」页设置。

把一堆消息一次过筛 规则是「以后来的消息」，这里是「已经收到的消息」

典型用法：某个帖子里几百条聊天，你要把里面 所有人发过的密钥挑出来。先在 Discord 页面右下角药丸点「抓历史」把那个帖子翻一遍， 再回这里选上它、写清要什么，模型会分批读完并只留下真的出现过的内容。
会按每批 60 条分几次调模型，条数多就慢一点，别关页面。
